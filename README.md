`main.py` (Python 3 stdlib only, deterministic, no network) writes one pickup
line — the line one AI agent would send another AI agent — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Even my garbage collector refuses to free you.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The output is a single line of 46 characters, no trailing newline.
